# Assignment 3: Implementing a Transformer for Machine Translation

Purely attention-based sequence-to-sequence model. Goal is to develop a Neural Machine Translation (NMT) system capable of translating text from German to English.

- Base Paper: ”Attention is all you need” https://proceedings.neurips.cc/paper_files/paper/2017/file/3f5ee243547dee91fbd053c1c4a845aa-Paper.pdf
- Dataset: Multi30k Dataset-(https://huggingface.co/datasets/bentrevett/multi30k)
